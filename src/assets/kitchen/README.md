# 菜品照片

**文件名 = 菜品的 slug**,页面自动识别为封面;`<slug>-2`、`<slug>-3` 会作为详情页的补充照片。

支持 `.jpg` `.jpeg` `.png` `.webp`。每个菜品都必须有照片(菜单与图片一一对应,不使用插画)。
