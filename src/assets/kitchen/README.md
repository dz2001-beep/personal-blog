# 菜品照片(自动识别)

把照片放进这个目录,**文件名 = 菜品的 slug**,页面自动把它当封面,不需要改任何代码。

支持 .jpg / .jpeg / .png / .webp。

## 优先级

1. 本目录下的图片(自动匹配,最高)
2. 数据里手写的 `cover` 字段(可指向外部 URL)
3. 都没有 → 文字版式卡片(菜名首字 + 暖色渐变),不会出现破图

## 建议规格

- 宽度 1200–1600px,JPG,单张 < 500KB
- 比例不限:卡片裁 4:3,详情大图裁 16:9
- 「做过的」建议连过程图和糊锅照一起放,比只有成品图更有说服力
